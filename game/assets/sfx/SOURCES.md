# Откуда звуки

Все — Kenney (www.kenney.nl), лицензия CC0 1.0: можно в коммерческих проектах, указывать автора не обязательно, можно распространять. Наборы скачаны с OpenGameArt, куда их выложил сам Kenney (пользователь `kenney`). Обработка: моно 44,1 кГц, тишина в начале срезана, пик −1 dBFS плюс поправка громкости звука, OGG Vorbis (`tools/audio/kenney_sfx.py`).
