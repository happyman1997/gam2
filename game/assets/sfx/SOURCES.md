# Откуда звуки

Все звуки — под CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/): можно в коммерческих проектах, указывать автора не обязательно, можно распространять. Источник — OpenGameArt; лицензия каждой страницы проверена (CC0), страницы с CC-BY, CC-BY-SA, GPL не используются. Наборы Kenney выложил сам Kenney (пользователь `kenney`). Обработка: моно 44,1 кГц, тишина в начале срезана, где указано — тон ниже, срез высоких, укорочено, подмешаны другие звуки, сжато для плотности, громкость выровнена по слышимой (A-взвешенной) громкости, пик не выше −1 dBFS, OGG Vorbis (`tools/audio/sfx_build.py`).
